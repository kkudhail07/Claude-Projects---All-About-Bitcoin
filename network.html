What these numbers mean

Price (GBP / USD)

What one bitcoin trades for right now. It moves constantly because it's set by a global, 24/7 market — not by any institution.

Mined to date

How many of the eventual 21 million coins have been issued. New coins arrive with each block and the rate keeps falling — so this line creeps toward 21M but never overshoots.

Latest block

The height of the most recent block added to the chain. A new one is found roughly every ten minutes, each one extending the shared ledger.

Reachable nodes

Independent computers running Bitcoin and checking every rule for themselves — the more there are, the harder the network is to censor or change. There are typically between 15,000 and 20,000 "publicly reachable" nodes at any given time. Counting "unreachable" private nodes hidden behind VPNs or Tor, the total active count is estimated to be much higher — anywhere from 40,000 to over 70,000 globally.

Next halving

Every 210,000 blocks (~4 years) the new-coin reward is cut in half. This countdown shows how many blocks remain until the next one.

Market cap

Price multiplied by the coins in circulation — a rough measure of Bitcoin's total size against other assets.
